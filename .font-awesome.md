# Font Awesome Configuration

## Integration

- **Method:** Locally hosted Font Awesome SVGs rendered by Web Awesome `<wa-icon>`.
- **Version:** 7.3.1 (`@fortawesome/fontawesome-free`).
- **License:** Free.
- **Families:** Classic (solid and regular), plus brands.

## Defaults

- **Style:** Solid.
- **Family:** Classic.

## Import Pattern

`src/assets/main.js` imports `setIconPath` from `/assets/webawesome/webawesome.js` and sets the icon path to `/assets/fontawesome/svgs`. `.eleventy.js` copies the installed package's `svgs` directory to that public path. No Font Awesome Kit or CDN is used.

Use `<wa-icon name="book-open" variant="solid" aria-hidden="true"></wa-icon>` for the reading action. Use `variant="regular"` for regular icons and `family="brands"` for social icons. Check that the SVG exists in the corresponding installed package directory before adding an icon.

## Conventions

- Place button icons in the `start` or `end` slot and keep decorative icons hidden from assistive technology.
- Give icon-only controls an accessible label.
- Preserve the existing `<wa-icon>` integration; do not introduce another icon library.
- Keep this configuration in version control so future icon additions use the same integration.
