# Agent guidance

Read `PROJECT_RULES.md` before changing this repository. It defines the project-wide language, architecture, visual, content, security, and delivery rules.

Use `skills/README.md` to select and read the applicable local skill before work that touches WordPress content synchronization, Eleventy generation, the theme, site QA, or releases.

Treat the whole public site as the scope. Check `docs/current-site-inventory.md` and the affected route families; never use the homepage as a proxy for the rest of the site.

Preserve all existing staged, unstaged, and untracked user work. Never edit generated `_site/` output directly.
